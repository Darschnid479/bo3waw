# Hurtigstart

1. Installer .NET 10 SDK på Windows.
2. Last ned den komplette v1.0-prosjektpakken og pakk ut filene i dette repoet.
3. Kjør `BUILD_WINDOWS.bat`.
4. Åpne `dist\win-x64\WaWtoBO3Converter.exe`.
5. Velg en WaW `.ff` eller redigerbar `.map`, og velg en separat eksportmappe.

**Merk:** `.ff` gir per nå bare et BO3-referansekart med objektplasseringer. Full geometri fra kompilerte kart rekonstrueres ikke.
